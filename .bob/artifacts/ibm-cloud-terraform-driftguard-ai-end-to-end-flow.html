Terraform
📦 TerraformRunner
Command allowlist enforced.
apply / destroy blocked.
→
1. terraform init
Initialises provider plugins.
IBM Cloud provider v2.6.2.
→
2. terraform validate
Checks configuration syntax
before hitting IBM Cloud APIs.
→
3. plan -refresh-only read-only
Refreshes remote state vs IBM Cloud.
Saves plan to temp file. Never applies.
→
4. show -json
Converts plan to structured JSON for parsing.
🔒 7 IBM Cloud Stage endpoint env vars injected at subprocess level: IBMCLOUD_IAM_API_ENDPOINT, IBMCLOUD_IS_NG_API_ENDPOINT, IBMCLOUD_GT_API_ENDPOINT and 4 others — routes all Terraform API calls to test.cloud.ibm.com instead of production.

→
🔎 Attribute Diff
before vs after per attribute.

Policy

100% deterministic.

→

Rules ordered: CRITICAL → HIGH

value regex.
